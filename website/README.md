# Documentation website workstream

**Owner:** platform partner. **Requirements:** [docs/prd/platform.md](../docs/prd/platform.md), section "Documentation website".

This directory will hold the public documentation website: getting started, concepts, integration guides, CLI, SDK and API references, the security model, limitations, changelog and pricing.

## Boundaries

- `docs/` at the repository root holds internal documents: PRDs, status, research and evidence. Publish only what the website pages copy or link on purpose.
- Every command and code sample on the website must run against the released package version.
- Never publish private seeds, sealed panel contents, provider keys or customer data.
